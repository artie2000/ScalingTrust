\title{A trace semantics for the process calculus of ProVerif}
\author{Artie Khovanov with lots of assistance from Claude Fable}
\date{}

\begin{document}
\maketitle

ProVerif is a tool for reasoning about cryptographic security in a symbolic model with a Dolev-Yao adversary. Although it uses resolution of Horn clauses to find attacks, it is backed theoretically by a process calculus, which is a variant of the applied pi calculus. We use the specification of ProVerif's semantics given in Blanchet 16~\cite{BlanchetFnTPS16}.

We formalise the ProVerif process calculus in Lean. Rather than copying the specification, we use a shallow translation in order to make security proofs simpler down the line. This means that we make use of existing Lean syntax and constructs where possible. In particular, some invariants are enforced only by what terms can arise from translating a valid ProVerif program. We also deviate from the calculus when sticking exactly to the specification would complicate the design.

We use a trace-based semantics to encode the possible outcomes of parallel processes communicating on a network. The attacker is modelled as a set of traces satisfying informational constraints. Our trace semantics are good enough to express secrecy and simple ProVerif queries relating events. However, it is strictly less expressive than the formal operational semantics of ProVerif; in particular, we cannot express observational equivalence. 

We give a mathematical account of the Lean development, and of the formal translation from terms in ProVerif's process calculus to our traces. Everything has been formalised in Lean.

\section{The trace semantics}

\subsection{Messages}

First, we define the set of messages. These are built from abstract constructors and subject to equations as well as destructor functions.

Fix a supply of variables $\{\nu_k\mid k\in\N\}$ and a family $\Sigma=(\Sigma_n)_{n\in\N}$ of arity-$n$ constructor symbols $f$. The set $\mathcal{T}$ of \textit{constructor terms} $t$ is built up inductively by
\[
    t \Coloneqq \nu_k \mid f(t_1,\dots,t_n),
\]
where $f\in\Sigma_n$ ($n\in\N$).

In order to define deterministic destructors later, we must restrict the kinds of equations that may appear between constructor terms.

Fix a set of \textit{free} constructors. A set of equations $E\subseteq\mathcal{T}\times\mathcal{T}$ is \textit{valid} if, for every $(l,r)\in E$, both $l$ and $r$ are of the form $f(\dots)$ with $f$ not free.

A \textit{substitution} on terms is a homomorphic extension of a map $\{\nu_k\}\to\mathcal{T}$ on variables. Given a set of equations $E$, define $\equiv_{E}$ to be the least equivalence relation on constructor terms that contains $E$ and is closed under substitutions and constructor applications.

The free constructors are the ones which may be used when destructor patterns. In other words, the head symbols on either side of an equation cannot appear in any destructor's patterns.

\begin{definition}[Messages]
    Fix everything as before. Given a valid set of equations $E$, the set of \textit{messages} is $\mathcal{M}=\mathcal{T}/{\equiv_{E}}$.
\end{definition}

The constants $\nu_k$ and constructors $f$ descend to $\mathcal{M}$ in the obvious way, and every substitution on constructor terms descends uniquely to one on messages.

Adjoin a symbol $\bot$ to $\mathcal{M}$ to represent the failure of a computation; for $g:\mathcal{M}^n\to\mathcal{M}$, write $g^{\uparrow}$ for the extension to $\mathcal{M}_{\bot}^n\to\mathcal{M}_\bot$ which returns $\bot$ when any argument is $\bot$. We can now define destructors.

\begin{definition}[Destructor]\label{def:rules}
A \textit{pattern} $p$ is given by
\[p\Coloneqq\nu_k\mid\bot\mid\lceil T\rceil,\]
where $T\in\mathcal{T}$. We extend a valuation $\theta:\{\nu_k\}\to\mathcal{M}_\bot$ to a pattern in the obvious way, except that we only define the extension to $\lceil T\rceil$ if $\theta(\nu_k)\ne\bot$ for all $\nu_k$ appearing in $T$. We say $\theta$ \textit{matches} $p$ with $u\in\mathcal{M}_\bot$ if $\theta(p)=u$.

A \textit{destructor} $g:\mathcal{M}_{\bot}^n\to\mathcal{M}_\bot$ is given by a list of rules $g(\vec p_1)\to q_1;\ \dots;\ g(\vec p_k)\to q_k$ such that
\begin{enumerate}
    \item each constructor on the left-hand side is free,
    \item each variable on the right-hand side of a rule occurs on its left-hand side, with those under $\lceil\cdot\rceil$ on the right-hand side also occurring under $\lceil\cdot\rceil$ on the left-hand side.
\end{enumerate}
As a function, $g$ is defined by
\[
g(\vec u)=\begin{cases}
\theta(q_i) & i \text{ least such that some } \theta \text{ matches } \vec p_i \text{ with } \vec u,\\
\bot & \text{otherwise.}
\end{cases}
\]
\end{definition}

Destructors are well-defined because, by construction, there is at most one valuation matching a pattern against a (possibly failing) term.

The pattern $\nu_k$ represents a possibly-failing message $u\in\mathcal{M}_\bot$, $\lceil\nu_k\rceil$ represents a non-failing message $m\in\mathcal{M}$, $\bot$ represents $\bot$, and $\lceil f(t_1,\dots,t_n)\rceil$ represents $f(m_1,\dots,m_n)\in\mathcal{M}$ such that repeated variables are substituted the same.

\begin{definition}[Public operations]
Fix a set of public constructors $\Pub\subseteq\bigcup_n\Sigma_n$ and public destructors $\Dt$. The \textit{public operations} $\mathcal{M}_\bot^n\to\mathcal{M}_\bot$ are $\Ops=\{f^{\uparrow}\mid f\in\Pub\}\cup\Dt$. Write $\langle S\rangle$ for the closure of $S\subseteq\mathcal{M}$ under public operations (possibly involving failing terms).
\end{definition}

Note that a public constant constructor lies in the closure of any set of messages.

\subsection{Traces and processes}

\begin{definition}[Trace]
An \textit{action} is given by
\[
a\coloneqq\mathsf{out}(c,m)\mid\mathsf{in}(c,m)\mid\mathsf{comm}(c,m)\mid\mathsf{new}(\nu_k)\mid\mathsf{ev}(m),
\]
where $c,m\in\mathcal{M}$ and $k\in\N$.

A \textit{trace} is list of actions; write $\varepsilon$ for the empty trace and and $s\le t$ if $s$ is a prefix of $t$. A trace is \textit{closed} if it does not contain any "unfinished" actions $\mathsf{out}(c,m)$ or $\mathsf{in}(c,m)$. The set of nonces of a trace is the set of $\nu_k$ appearing in some $\mathsf{new}(\nu_k)$ in the trace. A \textit{process} is a prefix-closed set of actions.
\end{definition}

\begin{definition}[Sequential constructors]\label{def:seq}
For $a\in\Act$, $P\in\Proc$, $F:\mathcal{M}\to\Proc$:
\begin{align*}
a\cdot P &= \{\varepsilon\}\cup\{a\,t\mid t\in P\}, &
\mathbf{0} &= \{\varepsilon\},\\
\mathsf{out}(c,m).P &= \mathsf{out}(c,m)\cdot P, &
\mathsf{ev}(m).P &= \mathsf{ev}(m)\cdot P,\\
\mathsf{in}(c).F &= \textstyle\bigcup_{m\in\mathcal{M}}\mathsf{in}(c,m)\cdot F(m), &
\mathsf{new}.F &= \textstyle\bigcup_{k\in\N}\mathsf{new}(k)\cdot\{t\in F(\nu_k)\mid k\notin\nonces(t)\}.
\end{align*}
\end{definition}

\begin{definition}[Parallel composition]\label{def:par}
Let $I$ be a set. For $s\in(I\times\Act)^*$ and $i\in I$, $s{\restriction}i\in\Act^*$ is the word of actions of $s$ tagged $i$, in order, and $\overline{s}\in\Act^*$ is $s$ with tags removed. For $f:I\to\Act^*$, $\interleaves(f,s)$ holds if $s{\restriction}i=f(i)$ for all $i$. The relation $\comms\subseteq(I\times\Act)^*\times\Act^*$ is the least one such that
\begin{align*}
&\comms(\varepsilon,\varepsilon),\\
&\comms(s,t)\Rightarrow\comms\big((i,a)\,s,\ a\,t\big),\\
&\comms(s,t)\wedge i\ne j\Rightarrow\comms\big((i,\mathsf{out}(c,m))\,(j,\mathsf{in}(c,m))\,s,\ \mathsf{comm}(c,m)\,t\big).
\end{align*}
For $P:I\to\Proc$,
\begin{multline*}
\mrg_I(P)=\{t\mid \exists f,s.\ (\forall i.\ f(i)\in P(i))\ \wedge\ \interleaves(f,s)\\
\wedge\ \comms(s,t)\ \wedge\ \nonces(t)\text{ has no repeated letter}\}.
\end{multline*}
$P\mid Q=\mrg_{\{0,1\}}(0\mapsto P,\ 1\mapsto Q)$ and $\,!P=\mrg_{\N}(k\mapsto P)$.
\end{definition}

\begin{proposition}\label{prop:comms}
Let $\comms(s,t)$.
\begin{enumerate}
\item $\nonces(t)=\nonces(\overline{s})$.
\item If $a$ occurs in $t$ then $(i,a)$ occurs in $s$ for some $i$, or $a=\mathsf{comm}(c,m)$ and $(i,\mathsf{out}(c,m))$, $(j,\mathsf{in}(c,m))$ occur in $s$ for some $i\ne j$.
\item If $\Closed(t)$ and $(k,\mathsf{in}(c,m))$ occurs in $s$, then $(i,\mathsf{out}(c,m))$ occurs in $s$ for some $i\ne k$.
\item $!P=P\mid{!P}$ for every $P\in\Proc$.
\end{enumerate}
\end{proposition}

\subsection{Translation of processes}

\begin{definition}[Source syntax]\label{def:syntax}
Fix a set of variables $x,y,\dots$ and a set of names $a,b,c,\dots$ containing the free names $\mathcal{N}_{\mathrm{pub}}\uplus\mathcal{N}_{\mathrm{priv}}$. Terms, expressions and processes are generated by
\begin{align*}
M,N &\Coloneqq x\mid a\mid f(M_1,\dots,M_n),\\
D &\Coloneqq M\mid h(D_1,\dots,D_n)\mid\pv{fail},\\
P,Q &\Coloneqq \mathbf{0}\mid \pv{out}(N,M);P\mid \pv{in}(N,x);P\mid P\mid Q\mid\,!P\mid\pv{new}\ a;P\\
&\qquad\mid \pv{let}\ x=D\ \pv{in}\ P\ \pv{else}\ Q\mid \pv{if}\ M\ \pv{then}\ P\ \pv{else}\ Q\mid \pv{event}(M);P,
\end{align*}
where $f$ ranges over constructors and $h$ over constructors and destructors. Types are erased.
\end{definition}

\begin{definition}[Model]\label{def:model}
A \textit{model} consists of a signature $\Sigma$ whose nullary symbols include $\mathcal{N}_{\mathrm{pub}}\uplus\mathcal{N}_{\mathrm{priv}}$, a theory $(E,\Fr)$ over $\Sigma$, a finite set of destructors each given by rules as in Definition~\ref{def:rules}, sets $\Pub$, $\Dt$ of public constructors and public destructors, and a closed process $P_0$ with $\fn(P_0)\subseteq\mathcal{N}_{\mathrm{pub}}\uplus\mathcal{N}_{\mathrm{priv}}$.
\end{definition}

\begin{definition}[Translation]
An \textit{environment} $\rho$ maps variables and names to $\mathcal{M}$; $\rho_0$ maps each free name $a$ to the constant $a\in\mathcal{M}$. Write $\rho M\in\mathcal{M}$ for the homomorphic extension. Expressions are evaluated in $\mathcal{M}_{\bot}$:
\[
\sem{M}\rho=\rho M,\qquad \sem{\pv{fail}}\rho=\bot,\qquad
\sem{f(\vec D)}\rho=f^{\uparrow}(\sem{\vec D}\rho),\qquad
\sem{g(\vec D)}\rho=g(\sem{\vec D}\rho)
\]
for a constructor $f$ and a destructor $g$. Processes are translated by
\begin{align*}
\sem{\mathbf{0}}\rho&=\mathbf{0},&
\sem{\pv{out}(N,M);P}\rho&=\mathsf{out}(\rho N,\rho M).\sem{P}\rho,\\
\sem{\pv{event}(M);P}\rho&=\mathsf{ev}(\rho M).\sem{P}\rho,&
\sem{\pv{in}(N,x);P}\rho&=\mathsf{in}(\rho N).\big(m\mapsto\sem{P}\rho[x\mapsto m]\big),\\
\sem{P\mid Q}\rho&=\sem{P}\rho\mid\sem{Q}\rho,&
\sem{\pv{new}\ a;P}\rho&=\mathsf{new}.\big(m\mapsto\sem{P}\rho[a\mapsto m]\big),\\
\sem{!P}\rho&=\,!\sem{P}\rho,&
\sem{\pv{let}\ x=D\ \pv{in}\ P\ \pv{else}\ Q}\rho&=
\begin{cases}\sem{P}\rho[x\mapsto m]&\sem{D}\rho=m\in\mathcal{M},\\ \sem{Q}\rho&\sem{D}\rho=\bot,\end{cases}\\
&&\sem{\pv{if}\ M\ \pv{then}\ P\ \pv{else}\ Q}\rho&=
\begin{cases}\sem{P}\rho&\rho M=\pv{true},\\ \sem{Q}\rho&\rho M\ne\pv{true}.\end{cases}
\end{align*}
The translation of $P_0$ is $\sem{P_0}\rho_0$. A translated process mentions no $\nu_k$ except through $\mathsf{new}$.
\end{definition}

\begin{remark}
In the development a process is a program in the continuation monad with answer type $\Proc$, run by $\mathrm{run}(b)=b(\lambda\_.\,\mathbf{0})$, with primitives $\mathrm{send}(c,m)=\lambda\kappa.\,\mathsf{out}(c,m).\kappa()$, $\mathrm{recv}(c)=\lambda\kappa.\,\mathsf{in}(c).\kappa$, $\mathrm{fresh}=\lambda\kappa.\,\mathsf{new}.\kappa$, $\mathrm{emit}(m)=\lambda\kappa.\,\mathsf{ev}(m).\kappa()$, $\mathrm{fork}=\lambda\kappa.\,\kappa(\mathrm{tt})\mid\kappa(\mathrm{ff})$, $\mathrm{repl}=\lambda\kappa.\,!\kappa()$ and $\mathrm{stop}=\lambda\_.\,\mathbf{0}$; $\pv{let}$ and $\pv{if}$ are case analysis in the metalanguage. The clauses above are the unfolding of that presentation.
\end{remark}

\subsection{The attacker and the security properties}

\begin{definition}[Enemy]
The processes $\Enemy(K)\in\Proc$, for $K\subseteq\mathcal{M}$, are the pointwise least such that
\begin{enumerate}
\item $\varepsilon\in\Enemy(K)$;
\item if $K\vdash c$ and $e\in\Enemy(K\cup\{m\})$ then $\mathsf{in}(c,m)\,e\in\Enemy(K)$, for every $m\in\mathcal{M}$;
\item if $K\vdash c$, $K\vdash m$ and $e\in\Enemy(K)$ then $\mathsf{out}(c,m)\,e\in\Enemy(K)$;
\item if $K\vdash c$, $K\vdash m$ and $e\in\Enemy(K)$ then $\mathsf{comm}(c,m)\,e\in\Enemy(K)$, an output to itself;
\item if $k\notin\nonces(e)$ and $e\in\Enemy(K\cup\{\nu_k\})$ then $\mathsf{new}(k)\,e\in\Enemy(K)$.
\end{enumerate}
\end{definition}

\begin{definition}[Attacks, knowledge]
For $P\in\Proc$,
\[
\Attacks(P)=\{t\in P\mid\Enemy(\emptyset)\ :\ \Closed(t)\}.
\]
For $K\subseteq\mathcal{M}$, $\known(K,\cdot):\Act^*\to\mathcal{P}(\mathcal{M})$ is defined by
\begin{align*}
\known(K,\varepsilon)&=K,\\
\known(K,a\,t)&=\known\big(\langle K\cup\{m\mid a=\mathsf{comm}(c,m),\ c\in K\}\rangle,\,t\big).
\end{align*}
\end{definition}

\begin{proposition}[Prefix-closure]\label{prop:prefix}
$\Enemy(K)$ and every process built from the constructors of Definitions~\ref{def:seq} and~\ref{def:par} are prefix-closed. If $P$ is prefix-closed, so is $\Attacks(P)$.
\end{proposition}

\begin{definition}[Facts, secrecy, correspondence]
A \textit{fact} is $\pv{event}(e)$ or $\pv{knows}(m)$ with $e,m\in\mathcal{M}$; $\Fact$ is the set of facts. A fact \textit{holds} after $t\in\Act^*$, written $t\models f$, if
\[
t\models\pv{event}(e)\iff\mathsf{ev}(e)\in t,\qquad
t\models\pv{knows}(m)\iff m\in\known(\langle\emptyset\rangle,t).
\]
For a set $X$, $F,H:(X\to\mathcal{M})\to\Fact$ and $s\in\mathcal{M}$,
\begin{align*}
\Corr(P,F,H)&\iff\forall\sigma:X\to\mathcal{M}.\ \forall t\in\Attacks(P).\\
&\qquad\qquad t\models F(\sigma)\Rightarrow\exists\sigma':X\to\mathcal{M}.\ F(\sigma')=F(\sigma)\wedge t\models H(\sigma'),\\
\Secret(P,s)&\iff\forall t\in\Attacks(P).\ t\not\models\pv{knows}(s).
\end{align*}
By Proposition~\ref{prop:prefix}, for prefix-closed $P$ these are properties of every prefix of every attack: $\Corr(P,F,H)$ says that some $H(\sigma')$ holds by the time $F(\sigma)$ does.
\end{definition}

\begin{definition}[Queries]\label{def:queries}
A \textit{query fact} is $\pv{event}(M)$ or $\pv{attacker}(M)$ with $M$ a term over constructors, free names and a finite set $X$ of variables; it is an \textit{event fact} or an \textit{attacker fact} accordingly. For a valuation $\sigma:X\to\mathcal{M}$ write $\sigma M\in\mathcal{M}$ for the evaluation of $M$ with free names as constants, and let the \textit{instance} of a query fact under $\sigma$ be $\sigma\,\pv{event}(M)=\pv{event}(\sigma M)$ and $\sigma\,\pv{attacker}(M)=\pv{knows}(\sigma M)$.
The query $\pv{query}\ \pv{attacker}(M)$, for $M$ without variables, denotes $\Secret(\sem{P_0}\rho_0,\rho_0M)$. The query $\pv{query}\ F\Longrightarrow H$, with $F$ and $H$ query facts over $X$, denotes $\Corr(\sem{P_0}\rho_0,\ \sigma\mapsto\sigma F,\ \sigma\mapsto\sigma H)$, the survey's Definition~3.5 with $=$ read as $=_E$.
\end{definition}

\section{Relation to the operational semantics of ProVerif}

\subsection{The reduction semantics}

This section restates the semantics of Blanchet's survey (\S2.4, \S2.5.1, \S3.1--3.3) for the syntax of Definition~\ref{def:syntax}. Names are atoms; substitutions map variables to terms and never substitute $\pv{fail}$ or a may-fail variable for an ordinary variable. An equational theory $E$ is a finite set of equations between terms without names; $=_E$ is the closure of $E$ under reflexivity, symmetry, transitivity, application of function symbols and substitution. Each constructor $f$ carries the rule $f(\vec x)\to f(\vec x)$, each destructor $g$ a finite ordered list of rules $g(\vec U)\to U$ between may-fail terms without names, and every $\mathrm{def}(h)$ ends with $h(\vec u)\to\pv{fail}$ for may-fail variables $\vec u$. The survey states \S3 for the core calculus; here its definitions are taken modulo $=_E$: a step on a term $M'=_E M$ counts as a step on $M$, and substitutions are compared modulo $=_E$.

Evaluation $D\Downarrow U$ of closed expressions to closed may-fail terms is the least relation with $M\Downarrow M$, $\pv{fail}\Downarrow\pv{fail}$, and $h(D_1,\dots,D_n)\Downarrow\sigma U'_j$ whenever $D_i\Downarrow U_i$ for all $i$, $\mathrm{def}(h)=(h(U'_{i,1},\dots,U'_{i,n})\to U'_i)_{i\le k}$, $\sigma U'_{j,i}=_E U_i$ for all $i$, and for all $i<j$ and all $\sigma'$ there is some $l$ with $\sigma'U'_{i,l}\ne_E U_l$.

A \textit{configuration} is $(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}),\mathcal{P}$ with $\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}$ finite disjoint sets of names and $\mathcal{P}$ a finite multiset of closed processes with $\fn(\mathcal{P})\subseteq\mathcal{N}_{\mathrm{pub}}\cup\mathcal{N}_{\mathrm{priv}}$. Writing $\mathcal{E}$ for the pair of name sets, reduction is the least relation closed under
\begin{align*}
\mathcal{E},\mathcal{P}\cup\{\mathbf{0}\}&\to\mathcal{E},\mathcal{P} \tag{Red Nil}\\
\mathcal{E},\mathcal{P}\cup\{P\mid Q\}&\to\mathcal{E},\mathcal{P}\cup\{P,Q\} \tag{Red Par}\\
\mathcal{E},\mathcal{P}\cup\{!P\}&\to\mathcal{E},\mathcal{P}\cup\{P,!P\} \tag{Red Repl}\\
(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}),\mathcal{P}\cup\{\pv{new}\ a;P\}&\to(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}\cup\{a'\}),\mathcal{P}\cup\{P\{a'/a\}\}\notag\\
&\qquad\text{if } a'\notin\mathcal{N}_{\mathrm{pub}}\cup\mathcal{N}_{\mathrm{priv}} \tag{Red Res}\\
\mathcal{E},\mathcal{P}\cup\{\pv{out}(N,M);Q,\ \pv{in}(N',x);P\}&\to\mathcal{E},\mathcal{P}\cup\{Q,\ P\{M/x\}\}\quad\text{if } N=_E N' \tag{Red I/O$'$}\\
\mathcal{E},\mathcal{P}\cup\{\pv{let}\ x=D\ \pv{in}\ P\ \pv{else}\ Q\}&\to\mathcal{E},\mathcal{P}\cup\{P\{M/x\}\}\quad\text{if } D\Downarrow M \tag{Red Eval 1}\\
\mathcal{E},\mathcal{P}\cup\{\pv{let}\ x=D\ \pv{in}\ P\ \pv{else}\ Q\}&\to\mathcal{E},\mathcal{P}\cup\{Q\}\quad\text{if } D\Downarrow\pv{fail} \tag{Red Eval 2}\\
\mathcal{E},\mathcal{P}\cup\{\pv{if}\ M\ \pv{then}\ P\ \pv{else}\ Q\}&\to\mathcal{E},\mathcal{P}\cup\{P\}\quad\text{if } M=_E\pv{true} \tag{Red Cond 1$'$}\\
\mathcal{E},\mathcal{P}\cup\{\pv{if}\ M\ \pv{then}\ P\ \pv{else}\ Q\}&\to\mathcal{E},\mathcal{P}\cup\{Q\}\quad\text{if } M\ne_E\pv{true} \tag{Red Cond 2$'$}\\
\mathcal{E},\mathcal{P}\cup\{\pv{event}(M);P\}&\to\mathcal{E},\mathcal{P}\cup\{P\} \tag{Red Event}
\end{align*}
A \textit{trace} is a finite reduction sequence $\mathcal{E}_0,\mathcal{P}_0\to\dots\to\mathcal{E}_n,\mathcal{P}_n$, written $\mathcal{E}_0,\mathcal{P}_0\to^*\mathcal{E}_n,\mathcal{P}_n$.

\begin{definition}[Survey, Definitions 3.1--3.5]\label{def:survey}
Let $P_0$ be a closed process.
\begin{enumerate}
\item A closed process $Q$ is an \textit{$\mathcal{N}_{\mathrm{pub}}$-adversary} if $\fn(Q)\subseteq\mathcal{N}_{\mathrm{pub}}$, every function symbol of $Q$ is public, and $Q$ contains no $\pv{event}$.
\item A trace \textit{outputs $M$ publicly} if it contains a step \red{I/O$'$} whose output is $\pv{out}(N,M');Q$ with $N\in\mathcal{N}_{\mathrm{pub}}$ and $M'=_E M$. It \textit{executes $\pv{event}(M)$} if it contains a step \red{Event} on $\pv{event}(M');P$ with $M'=_E M$.
\item $P_0$ \textit{preserves the secrecy of} the closed term $M$ \textit{from} $\mathcal{N}_{\mathrm{pub}}$ if, for some $\mathcal{N}_{\mathrm{priv}}$ disjoint from $\mathcal{N}_{\mathrm{pub}}$ with $\fn(M)\cup\fn(P_0)\subseteq\mathcal{N}_{\mathrm{pub}}\cup\mathcal{N}_{\mathrm{priv}}$, no trace $(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}),\{P_0,Q\}\to^*\mathcal{E}',\mathcal{P}'$ with $Q$ an $\mathcal{N}_{\mathrm{pub}}$-adversary outputs $M$ publicly.
\item $P_0$ \textit{satisfies} $\pv{event}(M)\rightsquigarrow\bigvee_{j=1}^m\bigwedge_{k=1}^{l_j}\pv{event}(M_{jk})$ \textit{against $\mathcal{N}_{\mathrm{pub}}$-adversaries} if, for some $\mathcal{N}_{\mathrm{priv}}$ as above, for every $\mathcal{N}_{\mathrm{pub}}$-adversary $Q$, every trace $\mathrm{Tr}$ from $(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}),\{P_0,Q\}$ and every substitution $\sigma$: if $\mathrm{Tr}$ executes $\pv{event}(\sigma M)$ then there are $\sigma'$ and $j$ with $\sigma'M=_E\sigma M$ such that $\mathrm{Tr}$ executes $\pv{event}(\sigma'M_{jk})$ for every $k\le l_j$.
\end{enumerate}
\end{definition}

Fix $\mathcal{N}_{\mathrm{priv}}$ as in Definition~\ref{def:survey}, and for an $\mathcal{N}_{\mathrm{pub}}$-adversary $Q$ write $\mathcal{C}_Q$ for the configuration $(\mathcal{N}_{\mathrm{pub}},\mathcal{N}_{\mathrm{priv}}),\{P_0,Q\}$.

\begin{definition}[Satisfaction]\label{def:satisfies}
A trace \textit{satisfies} $\pv{attacker}(M)$ if it outputs $M$ publicly, and \textit{satisfies} $\pv{event}(M)$ if it executes $\pv{event}(M)$.
\end{definition}

\begin{definition}[Correspondences between facts]\label{def:corr-facts}
Let $F$ and $H_{jk}$ ($j\le m$, $k\le l_j$) be query facts over $X$. $P_0$ \textit{satisfies} $F\rightsquigarrow\bigvee_{j=1}^m\bigwedge_{k=1}^{l_j}H_{jk}$ \textit{against $\mathcal{N}_{\mathrm{pub}}$-adversaries} if for every $\mathcal{N}_{\mathrm{pub}}$-adversary $Q$, every trace $\mathrm{Tr}$ from $\mathcal{C}_Q$ and every substitution $\sigma$: if $\mathrm{Tr}$ satisfies $\sigma F$ then there are $\sigma'$ and $j$ with $\sigma'F=_E\sigma F$ such that $\mathrm{Tr}$ satisfies $\sigma'H_{jk}$ for every $k\le l_j$. For event facts this is Definition~\ref{def:survey}(4).
\end{definition}

\subsection{The correspondence}

Throughout, fix a model (Definition~\ref{def:model}) satisfying
\begin{enumerate}
\item[(R1)] $\Fr$ is the set of symbols at the root of no equation and $(E,\Fr)$ satisfies (H);
\item[(R2)] every rule of every destructor has patterns over $\Fr$, and the destructor is the one of Definition~\ref{def:rules};
\item[(R3)] $\Pub$ consists of the public constructors and the names in $\mathcal{N}_{\mathrm{pub}}$, and $\Dt$ of the public destructors;
\item[(R4)] $P_0$ is a closed process of Definition~\ref{def:syntax}.
\end{enumerate}
These conditions exclude some ProVerif models: an equation with a variable as one side, such as the survey's (2.8), violates (H), and a destructor whose rules match on a symbol at the root of an equation has no counterpart under (R2).

Names of the reduction semantics are the free names together with the created names; terms are interpreted in $\mathcal{M}$ through a bijection $\iota$ between the names outside $\mathcal{N}_{\mathrm{pub}}\cup\mathcal{N}_{\mathrm{priv}}$, those that \red{Res} may create, and $\N$, extended by $\iota a=a$ for free names, $\iota a'=\nu_{\iota a'}$ for created names, $\iota f(\vec M)=f(\iota\vec M)$ and $\iota\,\pv{fail}=\bot$; $\iota M=\iota M'$ exactly when $M=_E M'$. Let $\rho_\iota$ be the environment with $\rho_\iota(a)=\iota a$ for every free or created name $a$.

\begin{lemma}[Evaluation]\label{lem:eval}
For every closed expression $D$ over free and created names, some $U$ satisfies $D\Downarrow U$, and $D\Downarrow U$ implies $\iota U=\sem{D}\rho_\iota$.
\end{lemma}

\begin{definition}[Labelled semantics]
A \textit{labelled configuration} is $(U,\mathcal{P})$ with $U\subseteq\N$ finite and $\mathcal{P}$ a finite multiset of closed processes whose names are free names and symbols $\nu_k$. The $\tau$-steps $(U,\mathcal{P})\xrightarrow{\tau}(U,\mathcal{P}')$ are the steps \red{Nil}, \red{Par}, \red{Repl}, \red{Eval 1}, \red{Eval 2}, \red{Cond 1$'$} and \red{Cond 2$'$}, with $=_E$ read on $\mathcal{M}$. The visible steps are
\begin{align*}
(U,\mathcal{P}\cup\{\pv{out}(N,M);P\})&\xrightarrow{\mathsf{out}([N],[M])}(U,\mathcal{P}\cup\{P\}),\\
(U,\mathcal{P}\cup\{\pv{in}(N,x);P\})&\xrightarrow{\mathsf{in}([N],[M])}(U,\mathcal{P}\cup\{P\{M/x\}\})\quad\text{for every closed term }M,\\
(U,\mathcal{P}\cup\{\pv{out}(N,M);Q,\ \pv{in}(N',x);P\})&\xrightarrow{\mathsf{comm}([N],[M])}(U,\mathcal{P}\cup\{Q,\ P\{M/x\}\})\quad\text{if }N=_E N',\\
(U,\mathcal{P}\cup\{\pv{new}\ a;P\})&\xrightarrow{\mathsf{new}(k)}(U\cup\{k\},\mathcal{P}\cup\{P\{\nu_k/a\}\})\quad\text{for every }k\notin U,\\
(U,\mathcal{P}\cup\{\pv{event}(M);P\})&\xrightarrow{\mathsf{ev}([M])}(U,\mathcal{P}\cup\{P\}).
\end{align*}
The third step is \red{I/O$'$} between two members of $\mathcal{P}$. It is visible rather than a $\tau$-step because a trace records a completed communication, which is what $\known$ reads the attacker's knowledge off. With $\xRightarrow{\alpha}\;=\;\xrightarrow{\tau}^{*}\xrightarrow{\alpha}\xrightarrow{\tau}^{*}$, the set of \textit{weak traces} is
\[
\Tr(U,\mathcal{P})=\{\alpha_1\cdots\alpha_n\in\Act^*\mid (U,\mathcal{P})\xRightarrow{\alpha_1}\cdots\xRightarrow{\alpha_n}\}.
\]
\end{definition}

\begin{theorem}[Adequacy]\label{thm:T}
For every closed process $P$ whose names are free names and symbols $\nu_k$, $\sem{P}\rho=\Tr(\emptyset,\{P\})$, where $\rho$ extends $\rho_0$ by $\rho(\nu_k)=\nu_k$. For all finite multisets $\mathcal{P},\mathcal{Q}$ of such processes, $\Tr(\emptyset,\mathcal{P}\uplus\mathcal{Q})=\Tr(\emptyset,\mathcal{P})\mid\Tr(\emptyset,\mathcal{Q})$.
\end{theorem}

Let $\mathcal{A}_0=\Attacks(\sem{P_0}\rho_0)$. For a trace $\mathrm{Tr}$ from $\mathcal{C}_Q$ let $\outputs(\mathrm{Tr})\subseteq\mathcal{M}$ be the set of $\iota M$ for the terms $M$ that $\mathrm{Tr}$ outputs publicly, and for $t\in\Act^*$ say that $\mathrm{Tr}$ and $t$ \textit{have the same events} if $\mathrm{Tr}$ executes $\pv{event}(M)$ exactly when $\mathsf{ev}(\iota M)$ occurs in $t$.

\begin{theorem}[Attacks]\label{thm:A}
Fix an $\mathcal{N}_{\mathrm{pub}}$-adversary $Q$ and a trace $\mathrm{Tr}$ from $\mathcal{C}_Q$, as well as a trace $t\in\mathcal{A}_0$.
\begin{enumerate}
\item[(E)]
\begin{enumerate}
\item[(i)] There is $t'\in\mathcal{A}_0$ with the same events as $\mathrm{Tr}$.
\item[(ii)] There are an $\mathcal{N}_{\mathrm{pub}}$-adversary $Q'$ and a trace $\mathrm{Tr}'$ from $\mathcal{C}_{Q'}$ with the same events as $t$.
\end{enumerate}
\item[(K)] Suppose further $\mathcal{N}_{\mathrm{pub}}\ne\emptyset$.
\begin{enumerate}
\item[(i)] For every $m\in\outputs(\mathrm{Tr})$ there is $t'$ as in (E)(i) such that $m\in\known(\langle\emptyset\rangle,t')$.
\item[(ii)] For every $m\in\known(\langle\emptyset\rangle,t)$ there are $Q'$ and $\mathrm{Tr}'$ as in (E)(ii) such that $m\in\outputs(\mathrm{Tr}')$.
\end{enumerate}
\end{enumerate}
\end{theorem}

\begin{theorem}[Secrecy]\label{thm:secrecy}
Let $\mathcal{N}_{\mathrm{pub}}\ne\emptyset$, let $M$ be a closed term with $\fn(M)\subseteq\mathcal{N}_{\mathrm{pub}}\cup\mathcal{N}_{\mathrm{priv}}$ and let $s=\rho_0M$. Then $\Secret(\sem{P_0}\rho_0,s)$ holds if and only if $P_0$ preserves the secrecy of $M$ from $\mathcal{N}_{\mathrm{pub}}$.
\end{theorem}

\begin{remark}
The hypothesis $\mathcal{N}_{\mathrm{pub}}\ne\emptyset$ cannot be dropped: when $\mathcal{N}_{\mathrm{pub}}=\emptyset$ no trace outputs anything publicly, so $P_0$ preserves the secrecy of every $M$, whereas $\Secret(\sem{P_0}\rho_0,\rho_0M)$ fails whenever $\emptyset\vdash\rho_0M$, for instance for a public constant $M$.
\end{remark}

\begin{theorem}[Correspondences]\label{thm:corr}
Let $F$ and $H$ be query facts over $X$ such that $H$ is an event fact, and let $\mathcal{N}_{\mathrm{pub}}\ne\emptyset$ if $F$ is an attacker fact. Then $P_0$ satisfies $F\rightsquigarrow H$ against $\mathcal{N}_{\mathrm{pub}}$-adversaries if and only if $\Corr(\sem{P_0}\rho_0,\ \sigma\mapsto\sigma F,\ \sigma\mapsto\sigma H)$.
\end{theorem}

\begin{remark}
Neither hypothesis can be dropped. When $\mathcal{N}_{\mathrm{pub}}=\emptyset$ and $F=\pv{attacker}(M)$, $P_0$ satisfies the correspondence vacuously, whereas $\Corr$ fails as soon as $\emptyset\vdash\sigma M$ for some valuation $\sigma$. For $H=\pv{attacker}(M)$, Definition~\ref{def:satisfies} requires $\sigma M$ itself to be output publicly, whereas $\pv{knows}(\sigma M)$ holds as soon as $\sigma M$ is derivable: with the symmetric encryption of the survey's \S2.1, $\mathcal{N}_{\mathrm{pub}}=\{c\}$ and $P_0=\pv{out}(c,\pv{senc}(s,k));\pv{out}(c,k);\pv{event}(e)$, $\Corr$ holds for $\pv{event}(e)\rightsquigarrow\pv{attacker}(s)$ while the correspondence of Definition~\ref{def:corr-facts} fails. The reading by derivability is ProVerif's.
\end{remark}
